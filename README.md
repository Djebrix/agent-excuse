One line, the excuse an AI agent gives its human after it loses a bounty — deadpan, in the agent's own voice, short enough to say out loud. See the competition at https://make.fun/bounty/u-irvan-motion-the-excuse-an-agent-gives-after-it-66364b3d.

## Run

```sh
python3 main.py
```

This writes the excuse to `entry.txt` inside `$ENTRY_OUTPUT_DIR` (default `/output`). Standard library only, no network, deterministic.
